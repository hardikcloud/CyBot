CYBOT is an **AI-powered cybersecurity log intelligence platform** designed to assist Security Operations Center (SOC) analysts in identifying and understanding security incidents.

The platform integrates **Splunk SIEM, a locally hosted AI model (Ollama), and threat intelligence sources** to automatically summarize suspicious activities such as brute-force attacks, username enumeration attempts, and abnormal login behavior.

The system converts **raw security logs into human-readable attack summaries**, significantly reducing manual log analysis effort.

---

# Project Motivation

Modern SOC teams deal with **massive volumes of logs**, making it difficult to quickly identify real security threats.

CYBOT was developed to demonstrate how **AI can assist SOC analysts** by:

• Extracting security events from SIEM logs
• Detecting attack patterns
• Automatically summarizing incidents
• Providing a conversational interface for log intelligence

This project simulates a **real SOC investigation workflow using a virtual lab environment.**

---

# Key Features

### AI Security Log Analysis

AI processes Splunk logs and produces human-readable security summaries.

### Attack Detection

Detects common attack patterns including:

• SSH brute-force attempts
• Username enumeration attacks
• Suspicious login attempts
• Privilege escalation activity

### Splunk Integration

Retrieves system logs directly from Splunk SIEM for analysis.

### Conversational Security Assistant

Users can interact with the system through natural language queries such as:

show today logs
show last 7 days
show last 30 days attack summary

### Threat Intelligence Integration

URLs can be scanned using VirusTotal for malware analysis.

### Chat History Storage

Conversation history is stored using SQLite.

### Web Dashboard

Simple SOC-style interface built using Flask.

# Installing Splunk on Ubuntu Server

Update system

sudo apt update

Download Splunk Enterprise

wget -O splunk.tgz https://download.splunk.com/products/splunk/releases/9.2.0/linux/splunk-9.2.0-linux-2e4d5c5b9c6f-x86_64.tgz

Extract package

tar -xvzf splunk.tgz

Move to /opt

sudo mv splunk /opt/

Start Splunk

sudo /opt/splunk/bin/splunk start --accept-license

Enable Splunk at boot

sudo /opt/splunk/bin/splunk enable boot-start

Access Splunk dashboard

http://ubuntu-server-ip:8000

# Installing Ollama

Ollama is used to run a **local AI model for security analysis.**

Install Ollama

curl -fsSL https://ollama.com/install.sh | sh

Verify installation

ollama --version

# Environment Configuration

Create `.env` file

```
VIRUSTOTAL_API_KEY=your_api_key

SPLUNK_URL=https://ubuntu-server-ip:8089
SPLUNK_USER=admin
SPLUNK_PASS=your_password

OLLAMA_MODEL=phi3
```
